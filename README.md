# 烛渊：仪式残响

Godot 4 原创暗黑童话风 2.5D Boss 战 MVP。当前处于阶段 0：工程基线。

## 启动

安装 Godot 4.x 后，在 Godot 项目管理器导入本目录的 `project.godot`，然后按 F6 运行主菜单或 F5 运行项目。

## 阶段 0 已有内容

- Godot 工程配置，逻辑分辨率 1920×1080，窗口允许伸缩。
- 主菜单入口与空的 3D 战斗场景。
- WASD/方向键移动、Shift/Space 闪避、鼠标左键/J 攻击、Esc 暂停的输入映射基线。
- 目录结构及 Git 忽略规则。

## 暂未完成

- Godot 导入及启动验证：执行环境暂未找到 Godot 可执行文件，官方包下载也未成功。
- 竞技场美术、角色、Boss、战斗系统与 HUD 均未进入开发。

## 操作基线

- 菜单：鼠标点击“进入仪式场”。
- 预留战斗映射：WASD/方向键移动，Shift/Space 闪避，鼠标左键/J 攻击，Esc 暂停。空场景当前没有对应战斗逻辑。
