# 第一关肉鸽循环 · 当前实现

## 进入与操作

运行 `res://scenes/chapter01/revoked_day.tscn`，或从标题进入第一关。
开场直接出生在办公室中央空地，并在雷贯光波、余烬回信、追索火种中三选一。确认后立即生成第一波，不再等待调查完毕或走到出口。未持有的卡不会显示或施放。滚轮只切换已持有卡，中键按住瞄准、松开释放；右键不取消。

办公室战斗结束获得15零钱和一次强化三选一。战后奖励优先提供一个已持有技能的变异和一个未持有技能，剩余位置可出现遗物；两个变异方向互斥。五张技能和所有已获得强化本局保留。

从办公室出口前往街道，靠近“出租屋入口”按E，选择分岔路线。四个支路完成后再交互进入出租屋，解开账单后与盖章者战斗。总结构为：办公室、街道入口、四个分岔节点、出租屋Boss，共七个节点。

## 支路

- 每次提供两个选项，至少一个是普通战或精英战。查看构筑不会重抽本次路线。
- 普通战随机4–6个敌人，15零钱和强化三选一。
- 精英战5–7个敌人，其中两个高生命精英，30零钱、强化三选一；遗物未满时额外遗物三选一。
- 休息恢复30生命，不超过上限。
- 事件可获得10零钱，或消耗15生命交换随机未持有遗物；生命必须大于15。
- 商店随机提供两个未持有遗物，20零钱购买一件；可以买一件或离开。
- 遗物最多四件，不能重复领取。战斗期间和奖励未领取时禁止进入出租屋。

## 十个变异

| 技能 | 方向一 | 方向二 |
| --- | --- | --- |
| 雷贯光波 | 三束分叉，每束65%伤害 | 满蓄力0.5秒后沿原线追加60%伤害 |
| 余烬回信 | 周围三个半径1、7伤害的小爆炸 | 火区半径提高35%，持续增加2秒 |
| 霜封档案 | 沿方向展开三个3×3冰阵，展开各4伤害 | 冻结普通怪被技能击败时产生半径2.5、10伤害冰环 |
| 追索火种 | 五枚，每枚8伤害 | 等待超过1秒的火种命中伤害提高50% |
| 逆风回廊 | 旋风沿释放方向以1.4单位/秒移动 | 结束风压24伤害，击退速度由4提高到7 |

分叉光波、扩大火区与连续冰阵均有对应预览。位移旋风检测地面和墙体，不能进入不可行走区域。Boss仍沿用原有硬控与牵引限制。

- 第二关：学校走廊、校门前厅、普通教室、档案自习室、错位钟表室；故乡街区、便利店、餐厅、旧商店、游戏店。

这些素材目前只建立索引，未直接套进第一关。第一关支路复用已有雨后街道，随机敌人、节点与奖励；没有把未校准的新图片当作带碰撞的可玩地图。后续需要逐张核对通道、碰撞、出生点、出口和镜头边界。

## 实现范围与限制

本轮可玩技能池为已有五张，20技能设计中的其余15张仍未实现。随机支路采用街道入口交互选路与街道战斗实例，不是已完成的新房间和走廊物理拼接，也没有随机重排地图碰撞。

当前构筑在本次关卡运行内保留，重新开始整关会清空重抽；尚未实现肉鸽局的存档、读档与跨章节继承。数值为测试起点，尚需实际完整通关平衡验证。
