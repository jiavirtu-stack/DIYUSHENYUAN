# 可叠加规则原型 · 雷贯光波实验室

## 如何体验

标题右下角点击“规则实验室 · 叠加与群怪”，或单独运行 `res://scenes/chapter01/beam_rule_lab.tscn`。

初始开启全部五个规则。左侧可独立关闭，或一键全部开启/清空。先清空体验基础弹，再逐项加入，比较组合结果。

中键短按松开为轻击，按住最多1秒蓄力后松开为重击。实验室光波独立冷却为0.65秒。玩家免伤；群怪生命24或38，默认清场1.4秒后刷新下一波，也可手动刷新。原五卡练习场和第一关不受实验室冷却影响。

## 同时生效的规则

| 规则 | 行为 |
| --- | --- |
| 分叉 | 释放三束扇射，每束72%伤害 |
| 反弹 | 每束遇固定墙体最多反射3次，消耗总飞行距离 |
| 贯穿 | 单束去程和回程各最多命中8个目标，同一目标在同一程只命中一次 |
| 回旋 | 终止去程后沿实际行进路径返回，包括反射拐点；回程重新记录命中，未带贯穿时回程也在首个敌人处终止 |
| 爆裂 | 直接命中后产生半径1.6的范围伤害，为原伤害45%；同一目标每次施放最多引发一次爆裂，分叉和回程共享此记录 |

基础单束伤害18–38。飞行速度26单位/秒，去程总长22单位，最长存活5秒。最多16次单帧出程碰撞迭代、32次回程路径迭代。爆裂伤害本身不再触发爆裂、分叉或新投射物，避免无限循环。

瞄准线显示开启分叉/反弹后的出程预测路径。路径池复用，切换规则不逐帧新建模型。已发射弹使用施放瞬间的规则快照，途中更改开关不改变已有弹体。

## 打击反馈

轻重攻击共享反馈函数，由参数区分：

- 轻击：18毫秒顿帧、较轻定向火花、小幅压缩与击退、较弱短促镜头冲击。
- 重击：45毫秒顿帧、更强压缩与击退、定向火花、局部短暂反色冲击。
- 三层程序合成声音分别提供低频冲量、中频材质声与高频短脆声，轻重只改变层级强度。
- 每个敌人有伤害数字与受击形变；重型声音、粒子和顿帧按真实时间限频，群体命中不会逐目标反复停帧。
- 镜头只做平移、不改变俯角，100毫秒内平方衰减；左侧滑条设0可完全关闭。
- 暂停冻结投射物；重置练习、死亡或场景退出清理投射物。顿帧中退出恢复时间倍率，防止返回标题后永久慢动作。

## 当前边界

这是可直接操作的战斗原型入口。规则目前接入雷贯光波实验室，尚未替换正式关卡的互斥变异奖励，也没有扩展到其他四张技能。这样可以先确认组合与反馈的手感，再决定规则如何作为局内道具投放。

实验室使用现有出租屋地图与敌人占位模型；没有在本轮新增角色美术。程序合成音效用于手感测试，后续可替换为制作完成的分层音效。

## 文件与检查

- `scripts/cards/beam_rules.gd`：规则快照、投射物、反弹、回程、爆裂、路径预览与上限。
- `scripts/cards/beam_lab.gd`：28敌人测试房、组合开关、波次与镜头强度。
- `scripts/combat_feedback.gd`：共享轻重反馈与退出恢复时间。
- `shaders/impact_local.gdshader`：局部冲击帧。
- `tests/beam_rules_smoke.gd`：真实首敌截断、贯穿与回程二次命中、组合、爆裂邻敌伤害、固定墙反弹、清理及顿帧退出。
- `tests/beam_lab_visual.gd`：真实渲染、组合预览复用与截图。

当前参数不是最终平衡；先以群怪清场手感与可辨识度为准。
