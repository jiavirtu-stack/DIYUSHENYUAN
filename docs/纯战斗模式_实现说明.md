# 纯战斗模式 · 当前正式流程

标题“开始游戏”默认进入本模式。场景：`res://scenes/chapter01/revoked_day.tscn`，`combat_only = true`。

## 一局流程

中央出生 → 起始技能三选一 → 第1波 → 战后强化三选一 → 自动下一波 → 第5波结束 → 自动盖章者Boss → 胜利结算 / 再来一局。

每次确认奖励后间隔0.8秒刷新下一波，不需要寻找出口、按E、选路线或跑地图。第3、5波为混合精英波，遗物未满时追加遗物三选一。选技与强化界面暂停，战斗途中不弹叙事对话，Boss第二阶段直接继续打。

## 敌人与手感

| 波次 | 数量 | 普通怪HP | 普通怪伤害 | 精英 |
| --- | --- | --- | --- | --- |
| 1 | 32 | 18 | 3 | 无 |
| 2 | 40 | 20 | 3 | 无 |
| 3 | 48 | 22 | 4 | 四只，60HP / 6伤害 |
| 4 | 56 | 24 | 4 | 无 |
| 5 | 64 | 26 | 5 | 四只，60HP / 6伤害 |

精英替换普通怪，不额外增加总数。每波从场地四侧筛选有效导航点，避开家具和玩家周围4单位范围。清场清除旧技能持续效果，保留装备、强化、生命和剩余CD。

近战攻速提高50%，距离和判定范围提高35%，保留轻击50毫秒、重击83毫秒的局部命中停顿。普通/精英敌人均有实时头顶血条。

## 退出正式流程的内容

没有调查资料、主观低语交互、账单解锁、街道探索、分岔选路、商店、休息事件或剧情弹窗。现有办公室背景里的家具仍作为战斗掩体，保留碰撞和导航。

Tab改为查看本局构筑。遗物“零钱袋”替换为“补给袋”：立即恢复15生命，战后额外恢复5。正式战斗不再发放或使用零钱。技能、变异与遗物的奖励选择保留，作为战斗中的成长决策。

旧叙事与探索源代码只保留用于回归参考，默认游戏入口不会进入；没有把旧流程作为玩家需要完成的前置。

## 验证

`tests/combat_only_smoke.gd`覆盖正式入口、没有探索节点、五波数量、战后自动衔接、精英遗物、无需账单直接Boss、不打断的第二阶段和通关。


## 清场批次更新

每波按8只一批生成，首波32只分4批。后续批次只保存生成计划，不提前创建或隐藏怪物。当前批次最后一只死亡后才触发下一批，先出现0.65秒橙黄色线框再现身；等待时间不会推进批次。第一波四批全部结束才弹强化，不能每批重复领取。

HUD区分波次、批次、当前批次存活数和本波含待出场的总剩余数。后续40/48/56/64怪分别分5/6/7/8批。

验证：`tests/clear_batch_smoke.gd`，包括留一只等待三秒不刷怪、最后一只死亡才推进，以及四批清完才奖励；`tests/combat_only_smoke.gd`已按逐批击杀验证五波到Boss。

## 技能视觉替换

“追索火种”替换为“暗影骷髅”：默认三枚像素骷髅环绕角色，自动追踪可见敌人，使用紫色幽影、绿色眼光及衰减拖尾，命中产生幽光碎片。独立CD9秒，保留原追踪与数值；相关变异改名为“五魂追猎”和“幽魂蓄势”。

根据用户提供的necro-skulls接口方向，在Godot中原生实现；没有直接引入JavaScript的pixelfx依赖，也不声称逐像素复现未提供的源特效。截图：`docs/card_skill_4.png`。五技能实际命中和渲染检查均通过。
