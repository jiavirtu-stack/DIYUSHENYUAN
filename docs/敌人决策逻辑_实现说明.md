# 敌人决策逻辑 · 当前实现

本实现参考房间动作肉鸽的战斗节奏，不声称复现《元气骑士》的内部算法。

优先级：死亡/暂停 → 命中停顿/冻结 → 攻击前摇 → 攻击后摇 → 检查视线 → 按职业选择移动或攻击。

- 无有效目标：待机。
- 被墙体遮挡：通过已有导航寻找接近目标的路线，不能隔墙开始攻击。
- 近战：追到1.45单位 → 锁定方向，前摇0.42秒 → 检查距离与正面方向后挥击 → 后摇0.32秒 → 等待攻击间隔。
- 远程：射程6.5单位；距离小于3时撤退，超过4.2才退出撤退；停步锁定方向0.55秒后发射直线弹，后摇0.48秒，冷却时侧移。
- 法师：射程8单位；距离小于3.8时撤退，超过4.8退出撤退；显示固定1.8×1.8落点，0.9秒后结算，玩家离开方框可躲避；死亡取消未完成法术。
- 攻击间隔：近战1.2–1.8秒，远程/法师2–2.8秒，从开始前摇时计时，前后摇期间不重新出招。
- 群怪移动加入近距离软分离；追击和撤退路径每0.18秒更新，避免每帧重新寻路。
- 顿帧和冻结期间不推进敌人前摇、冷却与移动；暂停同样冻结法术预警，不使用独立计时器偷偷结算。

验证：`tests/enemy_decision_smoke.gd`、`tests/melee_hitstop_smoke.gd`、`tests/combat_only_smoke.gd`。

## 分散站位与稳定路径修正

- 近战每0.9秒从存活且已现身的近战中安排最近四只作为前排；其余在约4单位外圈候场，不全部追到玩家脚下。
- 远程偏好5.5单位射击位置，法师偏好7单位；候选来自可通行导航格，需要有到达路径与对玩家的射线。
- 按出生方向保留接近扇区，位置打分考虑行走距离、同伴当前位置和同伴已选目标，减少抢同一站位。
- 目标保留1.6–2.5秒；法师2.5–3.8秒。玩家移动超过2.5单位或贴近时提前重选。合适的远程射击位置会停留，外围换位会完成到达目标的移动。
- 不再直接朝玩家坐标重算单步方向；缓存整段路径，按路点推进。仅在身体宽度的通道无障碍时跳过网格拐角；不可达时不会退化为朝墙直走。
- `tests/enemy_spacing_smoke.gd`检查前排名额、外圈目标、远程停留与24敌人导航。
- `tests/enemy_spacing_visual.gd`记录32敌人、玩家静止11秒的实际画面；本次观察贴近2单位的近战4只，3单位内远程/法师0只。该观察不是所有地图和站位的通用保证。
