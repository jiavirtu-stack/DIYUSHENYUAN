# Boss 动作观察与实现映射

来源是用户提供视频的本地关键帧；以下只记录可观察的姿态变化，不推断缺失帧的精确时长。

| 时间帧 | 观察到的姿态/节奏 | 本项目对应动作设计 |
|---|---|---|
| 00:00.00 | 开场 Boss 是较紧凑的仪式姿态，肢体向外分布，中心暗色核心明显 | `idle`：中心重心稳定，根蔓轻摆 |
| 00:04.24 / 00:12.71 | Boss 变成更明亮、展开的战斗姿态，外围枝状结构打开，周围同时有大范围特效 | `telegraph`：抬起并张开根蔓；`attack_barrage`：核心爆发动作 + 环形弹幕 |
| 00:21.19 | 强烈亮度爆发覆盖 Boss 主体，动作峰值集中 | `attack_slam`：举根后下砸，冲击帧与地面攻击同步 |
| 00:25.43 | Boss 高耸、枝冠和多条肢体展开，体量占据画面中央 | `attack_sweep`：宽幅根蔓横扫，让攻击期肢体跨度明显大于待机 |
| 00:29.66 / 00:38.14 | Boss 轮廓降低，进入贴近地面的姿态/结束状态 | `recovery` 回缩至 `idle`；死亡使用 `collapse` 伏倒帧 |

这些帧间隔较大，无法准确得出原作的逐帧动画、动画时长或状态转移。当前实现学习的是“收拢待机 → 抬起张开预警 → 大幅横扫/下砸/核心弹幕 → 回缩恢复”的运动节奏，并使用完全原创的角色图集。
