# 奥术施法法阵 · 当前接入

用户提供了 `pixelfx/fx/arcane/magic-circle-cast` 的JavaScript调用示例；本项目使用Godot原生shader实现同类施法表现，没有直接引入该JS库，也不声称精确复现未提供的模块源码。

当前作为五张技能共用的释放视觉：成功施放时在角色释放位置的地面展开，双环、符文刻度和六芒图案旋转闪亮后消散，总时长0.68秒。颜色跟随技能，不改变伤害、射程、命中、元素结算、CD或施法恢复时间。无效落点或冷却拒绝不生成法阵。

法阵固定在释放位置，不追随角色移动；暂停冻结时间；自然结束或技能转场清理时销毁。不包含碰撞体，不造成额外伤害。

文件：`scripts/cards/magic_circle_cast.gd`、`shaders/magic_circle_cast.gdshader`。测试：`tests/magic_circle_smoke.gd`检查成功触发、拒绝时不重复、暂停及清理；五技能物理回归检查原有数值。预览：`docs/magic_circle_cast.png`。
