# 《低语深渊》美术资产清单

版本：首版原型清单 v0.1；依据[需求确认记录](需求确认记录_低语深渊.md)。

## 美术总规范

- **画面类型**：Godot 4 的 2.5D 俯视场景；3D 地面与模块化环境，角色和大部分敌人用透明 Sprite3D/AnimatedSprite3D，所有碰撞与动画锚点落在地面。
- **参考方向**：借鉴参考视频的手绘笔触、粗细轮廓、夸张可读动作、暖红/赭石和深色环境的强对比；加入沉没村落与克苏鲁式暗紫、黑色污染。只借鉴整体艺术方向，不复刻原作角色、符号、场景细节、UI 或音效。
- **材质**：统一手绘非像素风；角色边缘清楚，地面细节比角色低一档；技能危险轮廓用红/黄高对比色，不用仅靠颜色区分。
- **角色枢轴**：Sprite3D 以脚底中心为世界锚点，帧间脚底高度和角色占格保持一致；攻击可超出基础身体轮廓。
- **纹理导入建议**：角色、图标与贴花使用透明 PNG；画面纹理过滤 Linear；细笔触资源先使用 Lossless/无损压缩；地面重复纹理开启 Repeat 与 mipmap。导入设置需在 Godot 实际画面核对。
- **帧率建议**：角色 8–12 FPS；明显蓄力/攻击关键动作 10–15 FPS；特效可按 12–18 FPS。最终依据击中可读性调节。
- **临时与最终区分**：灰盒仅用于 P0 的逻辑验证。进入内容验收前，所有玩家、敌人、Boss、场景地标必须替换为原创正式 PNG/纹理；禁止默认图标或纯色几何体作为正式美术。

## 动画制作拆分规范

| 角色 | 最低动作清单 | 首版帧数建议 |
|---|---|---|
| 调查员 | idle / move / attack / dodge / hurt / death | 4–8 帧/动作；idle 可 2–4 帧 |
| 普通近战敌人 | idle / move / telegraph / attack / hurt / death | 2–6 帧/动作 |
| 远程敌人 | idle / aim / telegraph / projectile-release / hurt / death | 2–6 帧/动作 |
| 精英 | idle / dash-telegraph / dash / summon / recover / hurt / death | 3–8 帧/动作 |
| Boss | idle / 3 种 windup / 3 种 attack / recovery / stagger / phase-transition / death | 4–10 帧/动作；优先保证预警和攻击关键帧 |

## 交付目录建议

新资产放在独立前缀，避免覆盖旧 MVP：

```text
assets/lowwhisper/characters/player/
assets/lowwhisper/characters/enemies/
assets/lowwhisper/characters/boss/
assets/lowwhisper/environment/tiles/
assets/lowwhisper/environment/props/
assets/lowwhisper/vfx/
assets/lowwhisper/ui/icons/
assets/lowwhisper/audio/sfx/
assets/lowwhisper/audio/music/
```

文件规则：`类别_对象_动作_方向_版本.png`，例如 `char_investigator_attack_front_v01.png`。每批资产附 `ASSET_SOURCES.md`，记录生成/绘制方式、提示词摘要、尺寸、透明度、网格与导入设置。
